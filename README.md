# Tribute Page

A simple Tribute Page created using HTML and CSS to honor and showcase the life, achievements, and contributions of an inspiring personality.

## Objective

The objective of this project is to design a visually appealing web page that presents information about a notable person in an organized and attractive manner.

## Features

* Responsive page layout
* Profile image and biography section
* Information about achievements and contributions
* Clean and user-friendly design

## Technologies Used

* HTML
* CSS

## Files

* tribute.html

## How to Run

1. Download or clone the project.
2. Open `tribute.html` in any web browser.
3. Explore the tribute page and its content.

## Outcome

This project helped in understanding the fundamentals of HTML and CSS, including page structure, styling, image handling, and content presentation. It also improved web design and layout skills.
